# Macritos

PWA de conteo de calorías con IA por foto. Next.js (App Router) + TypeScript + Tailwind + Supabase.

Reglas de desarrollo: [`AGENTS.md`](AGENTS.md). Contratos: [`docs/contracts.md`](docs/contracts.md). Plan: [`../plans/PLAN_MACRITOS.md`](../plans/PLAN_MACRITOS.md).

## Empezar

```sh
cp .env.example .env.local   # completar los valores
pnpm install
pnpm dev
```

Requiere Node ≥ 22 y pnpm.
